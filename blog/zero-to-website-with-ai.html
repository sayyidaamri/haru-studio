From zero to a live website in an afternoon with AI

What AI tools are genuinely good at when building a small site, and where you still need to think.

Raka WiratamaSep 5, 2026 · 10 min.

What AI is genuinely good at

Drafting page structure, writing first versions of copy, generating boilerplate code and explaining errors. Used well, it turns a blank page into a rough draft in minutes.

Where you still need to think

  • Positioning. AI will happily write generic copy. Only you know why customers choose you.
  • Accessibility and performance. Check contrast, keyboard use and page weight yourself.
  • Security. Never paste secrets into a prompt, and review any code that handles forms or payments.

An afternoon plan

  1. Write one sentence about who the site is for and what they should do.
  2. Ask for a page outline, then edit it ruthlessly.
  3. Generate the HTML and CSS, then make it yours: fonts, colours, real photos.
  4. Run Lighthouse and fix what it flags, starting with speed.
  5. Publish, then ask three customers to try it while you watch.
